# 임재윤의 부자되기 작전

🎮 [게임 바로 플레이하기](https://jaeyoon-rich-game-at3n.vercel.app/)

> 어떤 말도 안 되는 선택을 해도 100% 무조건 우주 억만장자가 되는 5분 픽셀 부자 육성 시뮬레이션 게임!

## 🕹️ 게임 소개

- **주인공**: 임재윤
- **플레이 타임**: 약 3 ~ 5분 (10개 메인 스테이지 + 무한 자본 모드)
- **승률**: **100% 무조건 승리 (패배 없음)**
- **특징**:
  - 로또를 사면 기계 오류로 1등 50회 동시 당첨!
  - 진흙탕에 얼굴을 박으면 신라 왕실 순금 유물 발굴!
  - 당근마켓에 다 쓴 휴지심을 올리면 만수르가 3,000억에 낙찰!
  - 선택을 거듭할수록 픽셀 캐릭터의 외형이 진화:
    - 🕶️ 픽셀 골드 선글라스 & 순금 목걸이
    - 🤵 명품 턱시도 & 양손 롤렉스 시계
    - 🏎️ 황금 슈퍼카(람보르기니 JY-1) 주차 & 전속 집사
    - 👑 순금 왕관 & JY AIR 개인 전용기 & 순금 백호랑이
    - 🪑 순금 옥좌 & 달(Moon)·화성 소유권 & 우주 자본의 절대신 강림!
  - 💸 **인터랙티브 돈 뿌리기**: 캐릭터나 버튼을 클릭하면 5만원권과 코인이 쏟아지는 피젯 머니레인
  - 🔊 **Web Audio 8-bit 사운드 엔진**: 외부 음원 파일 없이 경쾌한 칩튠 사운드 이펙트 내장

---

## 🚀 빠른 시작 (Local Development)

```bash
# 1. 패키지 설치
npm install

# 2. 로컬 개발 서버 실행 (http://localhost:3000)
npm run dev

# 3. 배포용 빌드
npm run build
```

---


## 🛠️ 기술 스택
- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Retro Pixel Font (Galmuri11)
- **Audio**: Web Audio API Synthesizer
- **Animation**: Canvas Confetti, CSS Keyframes
- **Build Tool**: Vite
